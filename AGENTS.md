# QR Extension Super Intelligent

- Öffentliches, kostenloses MIT-Projekt von OgulcanKaya68.
- Einstieg: SPEC.md, CONSTRAINTS.md, ANLEITUNG.md.
- Oberfläche und öffentliche Anleitungen auf Deutsch und Englisch; Commit-Nachrichten auf Deutsch.
- Keine externen Dienste oder nachgeladenen Skripte im Produkt.
- Keine Zieladressen dauerhaft speichern oder protokollieren.
- Abhängigkeiten im Lockfile festhalten, Bibliothekslizenzen im Paket erhalten.
- Vor Übergabe: npm test, npm run build, npm run test:browser, npm run lint:firefox, npm run check:public und npm audit.
- CONSTRAINTS.md nicht abschwächen, um Prüfungen zu bestehen.
- Seitenanalyse nur im aktiven Tab nach Nutzeraktion, keine dauerhafte Überwachung.
- Logo nur aus lokalem sichtbaren Bildausschnitt oder geprüftem Upload, keine entfernten Bilder oder SVG-Markup übernehmen.
- Keine privaten Rechnerpfade, Zugangsdaten, Sitzungsprotokolle oder Browserprofile veröffentlichen.
