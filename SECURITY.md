# Sicherheitsmeldungen / Security policy

## Deutsch

- Sicherheitskorrekturen konzentrieren sich auf die neueste veröffentlichte Version. Es gibt keinen zugesagten langfristigen Support älterer Versionen und keine garantierte Reaktionszeit.
- Vertrauliche Schwachstellen über GitHub **Security → Advisories → Report a vulnerability** im [Repository](https://github.com/OgulcanKaya68/qr-extension-super-intelligent/security) melden, sofern diese Funktion angeboten wird.
- Fehlt der private Meldeweg, ein öffentliches Issue ausschließlich mit der Bitte um einen vertraulichen Kontaktweg öffnen. Keine Angriffsschritte, betroffenen echten Daten, Tokens oder vollständigen vertraulichen URLs veröffentlichen.
- Für eine private Meldung: Version, Browser/Betriebssystem, reproduzierbare Schritte mit Beispieldaten, erwartetes Verhalten, Auswirkung und gegebenenfalls einen Lösungsvorschlag angeben.
- Nur eigene Daten und Systeme untersuchen. Für Tests keine Konten oder Logos Dritter ohne Erlaubnis verwenden.
- Allgemeine Fehler ohne Sicherheitsbezug gehören in die [Issues](https://github.com/OgulcanKaya68/qr-extension-super-intelligent/issues).

## English

- Security fixes target the latest published version. Older versions have no promised long-term support; no response-time guarantee is offered.
- Report vulnerabilities privately through GitHub **Security → Advisories → Report a vulnerability** in the [repository](https://github.com/OgulcanKaya68/qr-extension-super-intelligent/security), when available.
- If private reporting is unavailable, open a public issue asking only for a confidential contact channel. Do not disclose exploit steps, real affected data, tokens, or complete confidential URLs.
- Include the version, browser/OS, reproduction steps using sample data, expected behavior, impact, and a possible fix in the private report.
- Test only your own data and systems. Do not use other people's accounts or logos without permission.
- Report ordinary non-security bugs through [issues](https://github.com/OgulcanKaya68/qr-extension-super-intelligent/issues).
